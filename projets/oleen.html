OLEEN

Une application mobile de gestion de ressources, réalisée dans le cadre d'un devoir de lycée. C'est mon premier projet logiciel encadré, avec un sujet imposé et une date de rendu.

Terminé Devoir de lycée React Native · Expo

Voir le code sur GitHub →

Ce que c'est

Une application mobile permettant de gérer et d'exploiter des ressources. Le sujet venait du lycée : il fallait livrer une application qui fonctionne, sur téléphone, dans un temps donné.

Ce que j'ai fait

  • L'interface — la conception des écrans et la navigation entre eux.
  • Les fonctionnalités principales — la logique de gestion des ressources.
  • Les tests — vérifier que l'application reste utilisable et réactive sur un vrai téléphone.

Ce que j'en retiens

  • Un sujet imposé, ça change tout. Sur mes projets personnels, je décide de tout ; ici il fallait répondre à une demande précise, ce qui est plus proche de la réalité d'un studio.
  • Une date de rendu oblige à trancher. J'ai dû accepter de livrer une application simple mais qui marche, plutôt qu'une application ambitieuse à moitié faite.
  • Ce n'est pas ma direction. Le développement mobile ne m'attire pas autant que le jeu, mais il m'a fait manipuler des composants, un état d'application et une interface — et ça, ça sert partout.

Outils

  • React Native et Expo

  • Node.js
